# Contributing to PlantDoc

PlantDoc is a student prototype. Feedback is welcome, especially from agronomists, extension officers and native Hindi/Telugu speakers.

1. Open an issue describing the problem or suggestion.
2. For knowledge-base or translation changes, cite the source document (for example the NIPHM IPM package). Never add pesticide doses without a source.
3. Keep pull requests small and describe how you tested them.
4. Do not commit datasets, model weights (`.pt`, `.pte`), API keys or personal data.
